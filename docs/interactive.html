Generador de Etiquetas SAP

Documentación interactiva para usuarios y desarrolladores

Propósito

Automatizar la generación, revisión e impresión de etiquetas SAP desde Excel.

Tecnología

Python + PySide6 + openpyxl + QPrinter/QPainter.

Datos

No usa base de datos; trabaja con Excel y JSON local.

Salida

Vista previa nativa e impresión en SATO WS408.

¿Qué es este programa?

Es una aplicación de escritorio para generar etiquetas de inventario desde un archivo Excel, revisarlas antes de imprimir y enviarlas a la impresora configurada.

¿Para qué sirve?
  • Cargar información desde Excel.
  • Elegir filtros o etiquetas.
  • Ver una vista previa de las etiquetas.
  • Imprimir en la impresora definida.
¿Con qué fin se hizo?

Se creó para automatizar un proceso que antes era manual, lento y más propenso a errores.

Uso paso a paso
  1. Abrí el programa.
  2. Hacé clic en Seleccionar Excel.
  3. Elegí el archivo con los datos.
  4. Esperá la carga de registros.
  5. Hacé clic en Seleccionar filtros.
  6. Elegí uno o varios filtros/etiquetas.
  7. Presioná Generar etiquetas.
  8. Revisá la vista previa.
  9. Confirmá la impresión si todo está bien.
Requisitos
  • Windows.
  • Archivo Excel válido.
  • Impresora instalada.
  • Para imprimir: SATO WS408.
Errores comunes
  • El Excel no existe o está bloqueado.
  • No se detecta la impresora.
  • No hay filtros seleccionados.
  • La vista previa no coincide con lo esperado.
Esta sección está pensada para desarrolladores que retomen el proyecto y necesiten continuar sin perder contexto.
Descripción general

Aplicación de escritorio desarrollada en Python con PySide6 para leer datos desde Excel, procesarlos, previsualizar etiquetas e imprimirlas en una impresora térmica.

¿Usa base de datos?

No. El sistema no usa base de datos. El origen principal es el Excel y la configuración se guarda localmente en JSON.

Arquitectura
  • main.py → arranque de la app.
  • ui/ → ventanas y diálogos.
  • view_models/ → estado y coordinación.
  • services/ → Excel, validación, impresión y driver.
  • models/ → estructuras de datos.
  • utils/ → constantes, logging y configuración.
Flujo técnico
  1. main.py inicia Qt y carga configuración.
  2. El usuario selecciona el Excel.
  3. ExcelService extrae registros e imágenes.
  4. MainViewModel agrupa datos por filtro.
  5. El usuario selecciona etiquetas.
  6. PrintService renderiza la vista previa.
  7. driver_check.py valida la impresora.
  8. Se imprime en SATO WS408.
Buenas prácticas observadas
  • Separación de responsabilidades.
  • ViewModel para desacoplar UI y lógica.
  • Validación previa antes de imprimir.
  • Logging centralizado.
  • Mensajes amigables al usuario.
  • Configuración local sin hardcodear el flujo.
